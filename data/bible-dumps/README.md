# Local Bible dumps

Public-domain English SQL dumps in the scrollmapper `{PREFIX}_books` / `{PREFIX}_verses` shape.

| File | Version | Source |
| --- | --- | --- |
| `KJV.sql` | King James Version | https://github.com/scrollmapper/bible_databases |
| `ASV.sql` | American Standard Version (1901) | same |

NTV (default in the app) and RVR1960 are copyrighted and are **not** in this folder. Do not add Platense or Reina-Valera 1909 labeled as NTV/RVR1960.

Import: `npm run db:import-bible`
